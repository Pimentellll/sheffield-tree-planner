# Changelog

## 0.2.0 — unreleased local backend candidate

Minor capability expansion from the readiness-only package; shared contracts and integrated product acceptance remain gated.

- Strict domain models, derived JSON Schema/OpenAPI and TypeScript types, plus the implemented local HTTP API contract.
- Immutable typed SQLite scenarios, optimistic revision conflicts, source/asset rights admission and complete source-graph fingerprints.
- Bounded jobs with cancellation/deadline/recovery fences, separate view selections, immutable cached origins and nested result-to-input validation.
- Trusted hash-bound synthetic one-tree evaluator runtime and a reproducible real-HTTP positive/zero/stale/failure/recovery demonstration.
- Host-scoped model dispatcher, loopback domain transport, native tool schemas and fail-closed evidence/currentness checks. Local-model proof is opt-in; incomplete/model-invalid traces do not pass.
- Dependency-ready constrained-search consumer only; no real search or independent feasibility producer, real Sheffield site, frontend acceptance, Spark execution or scientific sign-off is claimed.
- Wheel/sdist version remains sourced solely from pyproject.toml. No commit, push, merge, tag, release, deployment or registry publication is implied by this entry.

- Installable, dependency-free Python diagnostic for local OpenAI-compatible inference and a strictly validated tool-observation round trip.
- Loopback-only transport, no proxies/redirects, bounded JSON responses and explicit failure receipts.
- SSH/tunnel template, Linux ARM64-pinned NVIDIA inference candidate and model-revision/checksum manifest.
- Event-day deployment and product-integration guide; no Spark or real-model execution is claimed by local protocol tests.
- PR checks build/install/smoke the diagnostic; an authorised matching version tag can create a private draft release. No tag, release or registry publication has been performed. The tag-triggered publication path remains unexercised.
